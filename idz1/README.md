## Часть 1. Аномалии
### Аномалии вставки
- нельзя добавить информацию о новом товаре, без создания заказа с ним
- нельзя зарегистрировать нового пользователя, без создания на него заказа

### Аномалии обновления
- нельзя обновить данные клиента без создания нового заказа
- нельзя обновить данные о цене продуктов, без заказа

### Аномалии удаления
- если удалить заказы пользователя, то и удалиться информация о пользователе
